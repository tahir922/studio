# Muhammad Tahir - Unity Game Developer Portfolio

Professional portfolio of Muhammad Tahir, an independent Unity Game Developer specializing in C#, gameplay systems, mobile game optimization, and Android development.

## Features
- **Project Showcase**: Detailed view of mobile games with links to Google Play.
- **Experience Timeline**: Professional history as a Game Developer.
- **Technical Skills**: Visual breakdown of technical proficiency.
- **Contact Integration**: Functional contact form and social links.
- **Legal Compliance**: Privacy Policy and Terms of Service for store verification.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Components**: Shadcn/UI
- **Icons**: Lucide React
- **Animations**: Tailwind Animate & Custom CSS
- **Email**: Resend

## Deployment
This project is optimized for deployment on Vercel or Firebase App Hosting.
