# **App Name**: Tahir Games Portfolio

## Core Features:

- Interactive Hero Section: A visually engaging hero section with a typewriter effect for the headline and subtle parallax animation to draw visitors in.
- Project Showcase: A grid-based display of game development projects with animated cards and a modal to display a more complete project summary. Supports image, video, and playable WebGL demo previews.
- Skills Visualization: Animated skill bars that dynamically fill on scroll to visually represent proficiency in various technologies.
- Experience Timeline: A scrollable timeline presenting professional experience, featuring concise bullet-point highlights extracted from the CV.
- CV Download: A dedicated and easy to locate section featuring the ability to download the applicant's CV.
- Contact Form Submission: A contact form to enable direct communication, forwarding submissions via email.

## Style Guidelines:

- Background: Dark slate (#0B1020) for a modern game-dev aesthetic.
- Primary: Teal (#3EE6C9) for interactive elements and key highlights, providing a modern contrast against the dark background.
- Accent: Orange (#FF8A3D) for CTAs, adding energy to the UI.
- Headline: 'Space Grotesk', sans-serif, for a bold, geometric title, suitable for the technology sector. Note: currently only Google Fonts are supported.
- Body: 'Inter', sans-serif, for clear and readable paragraphs, ideal for digital content. Note: currently only Google Fonts are supported.
- Custom game-UI icons for categories, actions, and skill indicators.
- Centered content layout with a wide hero section.
- Two-column project grid on desktop, stacked on mobile, for responsive viewing.
- Use Framer Motion-style animations for micro-interactions, transitions, and effects.
